## ⚠️ 3군 — 가능하나 밸런스/등장빈도 주의

- **블랙홀**(SS, 끌당+실명+도트): 강력. 무적 카운터 존재 전제.
- **회귀**(S, 전원 10초 전 복귀+속박): 위치기록 부담. SpacetimeCollapse 로직 확장 가능.
- **전체 디버프류**(봉인/그림의 떡/망상/저체온증/미세먼지/폭염): 한 판에 여럿 풀리면 게임 정지. 추첨 빈도/동시등장 제한 필요.
- **즉사류**(할복/슈퍼노바/핵/생자필멸/도박/삼진아웃): 능력게임 밸런스 파괴. 비추(밈성).

## ❌ 구현 불가 / 매우 어려움 (1.8.8 한계)

- **하이재킹 / 붙여넣기 / 마인드컨트롤류**: 타인 몸·입력 조종 불가(클라 입력 못 뺏음). 따라하기는 흉내만 가능.
